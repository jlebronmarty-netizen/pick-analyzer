# Multisport Today and model accuracy

User-requested structure: sport cards show aggregate settled model accuracy, link to each sport's engine/formula hub, then a combined daily slate appears below the cards. MLB's existing Pick/Edge/Equilizer/formula views and exact-contract histories remain available; NHL retains its separate source page.

Accuracy counts WIN/(WIN+LOSS), weighted by outcomes, not by averaging percentages. MLB regular-season totals include canonical forward Pick, Edge, Equilizer and the separately deduplicated official ML model. The known production model is regular-season-only; unknown model versions/years or an overlapping master model fail closed. MLB playoffs have a distinct total and never add the regular-season official sample. Formula tabs are views of the same records, not another cohort. Different models may select the same game: this is descriptive model-observation accounting, not independent game accuracy, a calibrated probability, certification or ROI. NHL keeps its complete MODEL_ONLY source history and unknown legacy model identities; no MLB phase is assigned to it. Overall is explicitly the operational sum of the displayed sport cohorts and fails closed if a connected cohort is unavailable.

The unified slate uses existing Pick 2 MLB game/card logic and the additive stored NHL calendar in Sports Edge Hub PR #20. Games without predictions remain visible. Namespace-qualified event IDs prevent cross-sport collisions. Official and MODEL_ONLY selections remain distinct; research entries show their projections in original units, without invented odds/probabilities. Edge is informational, names its market basis, excludes stale/started NHL forecasts and preserves the source's calculation. Original pick prices are separate from current snapshots. Source outages and missing calendars produce visible partial-coverage notices. Disconnected sports never contribute invented results or games.

Read-only: no database changes, model changes, copied credentials, new provider calls or schedulers. The 107-file MLB operational manifest stays unchanged. Existing home/Today server entrypoints are preserved. `/api/dashboard/multisport` exposes the same sanitized display contract for verification. NBA/NCAAB research work is not modified or promoted. Actual phone validation is not claimed.

Verification covers weighted metrics, phase isolation, duplicate model detection, unavailable/empty distinctions, original/current prices, incomplete calendars, sport/date/status filters, units and live readback. Production SHA, screenshot, data fingerprints and build/test evidence are recorded in the release receipt.
