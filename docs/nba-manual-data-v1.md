# NBA — datos compartidos V1 (revisión)
GET /api/nba/manual-data?date=YYYY-MM-DD and /nba-manual. Puerto Rico local day; historical final and compact rows exclude the selected local day. Observed history reconstructed at read time is descriptive, not a frozen historical pregame feature snapshot. Contract NBA_MANUAL_DATA_V1 is always PARTIAL until independent completeness checks pass. No provider calls, model or forecast writes, database mutations, new cron or provider ingestion.

## Sources and bounds
Existing BDL schedule snapshots, game_results, GOAT compact, operational box scores, immutable private GOAT originals (verify manifest, path, hash, player identities and score sums using the existing originalContext and verifiedArchivedPlayerFinal helpers), archived daily scoreboards and pregame context, matchup observations. Original archive read budget: 180 objects and 768 KiB compressed, batches of ten, bounded runtime cache of 320 verified objects; shared decision board cache and budget are unchanged. Exact counts, duplicate and conflict checks, 45-second request bound; no raw private archive payload returned. Periods exclude OT from second half and require reconciled totals. Missing rows and incomplete participation are not substituted by zero. Latest observed team is not proof of current roster. Matchups are historical observations, not today's assignments.

## Access and integration
The NBA manual page and API follow the current NBA Decision Board private deployment and Vercel authentication boundary. Production API rejects the public alias. The private Site will need an independently authorized server-side integration; do not expose GOAT credentials or relax Vercel access to connect it. Site editing tools are currently unavailable in this chat. No modification to NHL/NCAAB or their refresh automation.
