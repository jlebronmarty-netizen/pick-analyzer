# NBA manual data V1 — draft
Read-only GET /api/nba/manual-data?date=YYYY-MM-DD and /nba-manual. Uses archived BDL schedule, game_results and compact GOAT player history. No provider requests, database writes, model adjustments or cron changes. Dates use America/Puerto_Rico; history excludes games on the selected local day. Exact counts, bounds and duplicate checks guard reads. Observed results are not official standings; recent rows are not certified consecutive history. Player IDs and last observed team are not current roster evidence. The report is always PARTIAL until archive reconciliation is implemented.
Pending: original GOAT final/period reconciliation, player directory, injury/lineup and matchup normalization, integration into existing NBA navigation, private Site access, tracker and automated refresh. Do not merge before build and real-data verification. No private raw archive payload is returned.
