# Documentation Structure

Sprint 0 establishes the target documentation structure:

- `/README.md`
- `/START_HERE.md`
- `/docs/README.md`
- `/docs/MASTER_PROGRAM`
- `/docs/RELEASES`
- `/docs/PRODUCT`
- `/docs/ARCHITECTURE`
- `/docs/CERTIFICATION`
- `/docs/HISTORY`

Legacy documents remain available until they are safely moved in bounded batches with link validation.
