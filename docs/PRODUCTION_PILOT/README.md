# Production Pilot Week

Status: `ACTIVE`

Production Pilot Week is the monitored real-world validation period after MC-08H Production Readiness certification.

## Scope

- Duration: 5-7 days.
- Current pilot day: 2.
- MC-03: not started.
- Purpose: observe the product as a daily betting decision tool before any Multi-Sport Expansion work.

## Rules

- No prediction formula changes.
- No Official Pick policy changes.
- No scheduler cadence changes.
- No provider budget changes.
- No settlement, learning, Current Era, Replay or model configuration changes.
- A no-bet day is valid when evidence is fresh, policy gates are honest and unsupported or stale evidence is not shown as actionable.
